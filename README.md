# NuevaMente

Sistema Inteligente de Adaptación y Generación de Contenido Educativo.

## Estructura del repositorio

- `backend/` — Backend, integraciones y despliegue.
- `frontend/` — Interfaz de usuario.
- `ia/` — Data & IA: RAG, embeddings, LLM y validación.
- `data/` — Datos y documentos de prueba.
- `docs/` — Documentación técnica y decisiones arquitectónicas.

## Organización del desarrollo

Cada equipo es responsable del código de su componente y de mantener la documentación mínima necesaria para instalar, ejecutar y entenderlo.
